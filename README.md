# AI Integrator Bangla Lab

AI Integrator Bangla Lab ভবিষ্যৎ এআই ইন্টিগ্রেটরদের জন্য বাংলা-প্রথম অনুশীলন ল্যাব।

## শিক্ষার্থী-মুখী ইন্টারফেস লেখা

- নেভিগেশন: হোম
- হিরো উপশিরোনাম: ভবিষ্যৎ এআই ইন্টিগ্রেটরদের জন্য বাংলা অনুশীলন ল্যাব
- ফুটার নোট: লগইন নেই। ব্যাকএন্ড নেই। এপিআই কী নেই। শুধু নিরাপদ পাবলিক শেখার জন্য।

## ভাষা নির্দেশনা

শিক্ষার্থীদের জন্য দেখা যায় এমন নেভিগেশন, ফুটার নোট, লেবেল, সহায়ক লেখা, এবং ব্যাখ্যামূলক ইন্টারফেস লেখা বাংলা-প্রথম হবে। প্রযুক্তিগত শব্দ দরকার হলে বাংলা উচ্চারণ ব্যবহার করতে হবে।

## নির্ভরতা নির্দেশনা

নির্ভরতার সংস্করণ হিসেবে অস্পষ্ট সর্বশেষ সংস্করণ রাখা যাবে না। প্রতিটি নির্ভরতার জন্য স্থিতিশীল ও স্পষ্ট সংস্করণ ব্যবহার করতে হবে।

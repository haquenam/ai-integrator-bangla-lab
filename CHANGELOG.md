## Version 0.5.0

Practice brief builder release.

Included interactive অনুশীলন ব্রিফ নির্মাতা with business type, problem type, assistant type, difficulty level, learning stage, generated practice brief, copy action, reset action, and browser local storage saving.

Interactive readiness dashboard release.

Included প্রস্তুতি যাচাই dashboard with checklist, score, readiness level, progress percentage, browser local storage saving, reset action, copy summary action, last updated date, and next step recommendations.

Video and ecosystem branding release.

Included embedded videos for the first 4 roadmap modules and Tech Talks Bangla ecosystem branding.

## Version 0.2.0

Roadmap release.

Included 10 module AI Integrator roadmap, Target 100K section, and Vision 2028 section.

## Version 0.1.0

Initial foundation release.

Included static Vite React application, GitHub Pages deployment, Bangla first interface, home page, hero section, placeholder learning sections, and footer.
